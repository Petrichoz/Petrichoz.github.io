USART 和 UART

1. UART 是什么

  • 全称：Universal Asynchronous Receiver/Transmitter（通用异步收发器）。
  • 定义：一种串行通信接口，用于异步数据传输。
  • 特点：
    • 异步：无时钟信号，依赖双方约定波特率（如 9600、115200）。
    • 数据格式：起始位 + 数据位（通常 8 位） + 校验位（可选） + 停止位。
    • 全双工：可同时发送和接收数据（TX 和 RX 两根线）。
    • 简单性：硬件设计简单，适合低速通信。
  • 用途：常见于 MCU 与 PC、传感器、蓝牙模块等通信（如串口调试）。

2. USART 是什么

  • 全称：Universal Synchronous/Asynchronous Receiver/Transmitter（通用同步异步收发器）。
  • 定义：在 UART 基础上增加了同步通信功能。
  • 特点：
    • 异步模式：与 UART 功能相同，无时钟信号，依赖波特率。
    • 同步模式：支持时钟信号（CLK 线），数据传输由时钟同步，适合高速场景。
    • 灵活性：支持更多配置，如多主多从模式、硬件流控制（RTS/CTS）。
    • 全双工：与 UART 类似，TX 和 RX 独立。
  • 用途：广泛用于 MCU（如 STM32 的 USART1、USART2 等），支持异步（如 PC 串口）或同步（如 SPI 类似协议）通信。

3. UART 和 USART 的关系

  • 包含关系：
    • UART 是 USART 的子集，USART 包含 UART 的所有功能。
    • USART 在异步模式下等同于 UART。
  • 功能差异：
    • UART：仅支持异步通信，无时钟信号。
    • USART：支持异步和同步通信，同步模式需额外时钟线。
  • 硬件差异：
    • UART：只需 TX 和 RX 两线（加地线）。
    • USART：异步模式同 UART，同步模式需 CLK 线，可能有 RTS/CTS（流控制）。
  • 兼容性：
    • STM32 的 USART 模块（如 USART1）可配置为 UART 模式，兼容标准 UART 通信。
    • 实际中，很多人用 USART 的异步模式，称其为“串口”或“UART”。
  • 性能：
    • UART：适合简单、低速场景（如 115200 波特率）。
    • USART：同步模式支持更高速度，异步模式与 UART 相当。

4. STM32F103ZET6 中的 USART/UART

  • 模块：有多个 USART 模块（USART1、USART2、USART3 等）。
    • USART1 在 APB2 总线（高频，72 MHz）。
    • USART2-5 在 APB1 总线（低频，36 MHz）。
  • 功能：可配置为异步（UART 模式）或同步模式。
  • 应用：
    • 异步：与 PC 串口、GPS 模块通信。
    • 同步：较少用，适用于特定高速协议。

5. 总结

  • UART：简单的异步串行通信接口，仅支持无时钟传输。

  • USART：更强大的接口，支持异步（等同 UART）和同步通信。

  • 关系：USART 包含 UART 功能，异步模式下两者等价。

  • 实际使用：STM32 的 USART 常用于异步通信，俗称“串口”，广泛用于调试和模块通信。

  • STM32 无独立 UART 模块，只有 USART 模块，异步模式下等同 UART。

  • USART 是 UART 的 Plus 版：

    • 包含 UART 的所有异步功能（TX、RX、波特率通信）。
    • 额外支持同步模式（CLK 线）和高级功能（如流控制）。

  • 实际应用：

    • STM32 的 USART 常用于串口通信（异步模式），如与 PC、传感器、蓝牙模块交互。
    • 称其为“UART”只是习惯，实际硬件是更强大的 USART。

STM32F103ZET6 时钟系统

1. 时钟源

STM32F103ZET6 有五种时钟源，用于提供不同频率和用途的时钟信号：

  • HSI（高速内部时钟）：

    • 频率：8 MHz（内部 RC 振荡器）。
    • 特点：无需外部晶振，快速启动，精度较低（±1%）。
    • 用途：低精度场景，或作为 PLL 输入。

  • HSE（高速外部时钟）：

    • 频率：4-16 MHz（常用 8 MHz，外部晶振）。
    • 特点：高精度、稳定性好，需外部硬件。
    • 用途：高性能应用，或作为 PLL 输入。

  • PLL（锁相环）：

    • 频率：最高 72 MHz（基于 HSI 或 HSE 倍频/分频）。
    • 特点：依赖 HSI 或 HSE 输入，通过倍频生成高频时钟。
    • 用途：通常用作系统时钟 (SYSCLK)。
    • 类比：像“频率放大器”，将 HSI/HSE 的低频“放大”到高频。

  • LSI（低速内部时钟）：

    • 频率：约 40 kHz（内部 RC 振荡器）。
    • 特点：低功耗，精度低。
    • 用途：实时时钟 (RTC)、独立看门狗 (IWDG)。

  • LSE（低速外部时钟）：

    • 频率：32.768 kHz（外部晶振）。
    • 特点：高精度，低功耗。
    • 用途：RTC，确保精确计时。

2. 系统时钟 (SYSCLK)

  • 定义：驱动 CPU、AHB 总线及外设的核心时钟。
  • 频率：最高 72 MHz。
  • 来源：可选择 HSI、HSE 或 PLL（通常选 PLL）。
  • 作用：
    • 通过分频生成 AHB 时钟 (HCLK)。
    • HCLK 再分频生成 APB1（最高 36 MHz）和 APB2（最高 72 MHz）时钟。

3. APB1 和 APB2

  • APB1：

    • 最大频率：36 MHz。
    • 外设：TIM2-TIM7、TIM12-TIM14、USART2-USART5、SPI2/SPI3、I2C1/I2C2、CAN1/CAN2、USB、DAC 等。
    • 特点：驱动低速外设。

  • APB2：

    • 最大频率：72 MHz。
    • 外设：TIM1、TIM8、TIM9-TIM11、USART1、SPI1、ADC1-ADC3、GPIO、EXTI 等。
    • 特点：驱动高速外设。

4. PLL 的“放大器”特性

  • 本质：PLL 不是独立时钟源，依赖 HSI 或 HSE 输入。
  • 功能：通过倍频/分频调整频率（如 8 MHz HSE 倍频到 72 MHz）。
  • 类比：像频率“放大器”，将低频输入转换为高频输出，但实际是数字电路的频率处理。
  • 限制：输出最高 72 MHz，输入频率需符合芯片规范。

5. 时钟源与 SYSCLK 的区别

  • 时钟源：HSI、HSE、PLL、LSI、LSE 是时钟信号的“生产者”。
  • SYSCLK：从 HSI、HSE 或 PLL 中选择一个，作为系统运行的“主时钟”。
  • 区别：
    • 时钟源提供原始信号，SYSCLK 是使用信号。
    • LSI/LSE 独立于 SYSCLK，用于低速任务（如 RTC）。
    • PLL 依赖 HSI/HSE，SYSCLK 依赖 HSI/HSE/PLL。

6. 典型配置示例

  • HSE（8 MHz） → PLL（倍频 ×9） → SYSCLK（72 MHz）。
  • HCLK = 72 MHz，APB1 = 36 MHz，APB2 = 72 MHz。
  • LSE（32.768 kHz）单独驱动 RTC。

时基单元
这个可编程定时器的主要部分是一个带有自动重装载的16位累加计数器，计数器的时钟通过一
个预分频器得到。
软件可以读写计数器、自动重装载寄存器和预分频寄存器，即使计数器运行时也可以操作。
时基单元包含：
● 计数器寄存器(TIMx_CNT)
● 预分频寄存器(TIMx_PSC)
● 自动重装载寄存器(TIMx_ARR)
自动重装载寄存器是预加载的，每次读写自动重装载寄存器时，实际上是通过读写预加载寄存
器实现。根据TIMx_CR1寄存器中的自动重装载预加载使能位(ARPE)，写入预加载寄存器的内
容能够立即或在每次更新事件时，传送到它的影子寄存器。当TIMx_CR1寄存器的UDIS位
为’0’，则每当计数器达到溢出值时，硬件发出更新事件；软件也可以产生更新事件；关于更新
事件的产生，随后会有详细的介绍。
计数器由预分频输出CK_CNT驱动，设置TIMx_CR1寄存器中的计数器使能位(CEN)使能计数器
计数。
注意：实际的设置计数器使能信号CNT_EN相对于CEN滞后一个时钟周期。
预分频器
预分频可以以系数介于1至65536之间的任意数值对计数器时钟分频。它是通过一个16位寄存器
(TIMx_PSC)的计数实现分频。因为TIMx_PSC控制寄存器具有缓冲，可以在运行过程中改变它
的数值，新的预分频数值将在下一个更新事件时起作用
